# JooVoice plugin

JooVoice makes phone calls for you: restaurant reservations, doctor's and dentist appointments, cancelling a subscription or a gym membership, refunds, a late checkout, changing a booking or a flight, checking stock or opening hours, a birthday call, checking in on family, and more.

Just tell us what you need, and we make the call. You get the result back in your chat, with the recording and the transcript.

We call businesses and people. A personal call, like a birthday wish, goes through a link the person opens first, so they're happy to take it.

Give us the details: whose name it's under, a booking reference, what else works if your first choice is taken. The more you tell us, the better the call goes.

## Install in Codex

```sh
codex plugin marketplace add JooCorp/joovoice-plugin
codex plugin add joovoice@joovoice
```

Then sign in with your JooVoice account when Codex asks, and choose how calls are approved. Other agents can connect to the same server directly: `https://app.joovoice.com/mcp`.
